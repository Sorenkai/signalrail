# Restricted: pending licence review

These Carlisle pilot files contain data derived from Network Rail **SMART** reference data (berth ids and berth step rows for TD area CL):

- `carlisle-pilot-results.json`: git-ignored;
- `carlisle-phase1-geography.json`: git-ignored;
- `CARLISLE_PILOT.md` (the report): excluded locally through `.git/info/exclude`, so formatting checks still apply.

Network Rail's licence and redistribution terms for SMART have not yet been confirmed (`data/sources.json`: `licence.confirmed: false`). Until they are, these files are kept local and must not be committed or published (DECISION_LOG D-016, D-019). This is a decision pending confirmation, not a statement that redistribution is prohibited.

The JSON files are regenerated by `tools/pilot-carlisle.ts --out <file>` and `npm run data:assess-geography -- --dataset carlisle`. Both need the owner's private SMART and CORPUS files; the pilot tool also needs the CIF.
