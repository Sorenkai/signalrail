## Blockers

### B-CE438 (unknown_signal_function, evidence: unknown)

CE438 stands at the inside node of cut-north-up-main, facing into play, and OSM gives it no railway:signal:<category> tag, so its function is unknown and movement never passes it (D-033). Every Up Main entry from the north (rt-um-fringe-ce336) stops there.

- **Records:** `osm-sig11954024796`, `rt-um-fringe-ce336`, `cut-north-up-main`
- **Needed:** A source stating CE438's function: an OSM category tag from survey, or a signalling plan
- **Proposed change:** If CE438 is a main signal, split rt-um-fringe-ce336 at it (fringe -> CE438, CE438 -> CE336); if it is a repeater or distant, no route change. Neither is assumed.
- **Groups:** `up-main-north-to-south` (72), `terminates-north-bays` (17)

### B-CE263 (unknown_signal_function, evidence: unknown)

CE263 stands at the inside node of cut-wcml-south-up, facing out of play towards Penrith, with no OSM category: any Up Main exit to the south would have to pass it, so none can be run.

- **Records:** `osm-sig11955498422`, `cut-wcml-south-up`
- **Needed:** A source stating CE263's function (OSM category tag from survey, or a signalling plan)
- **Proposed change:** If main: an exit route CE263 -> fringe on cut-wcml-south-up; if a repeater/distant: the exit route may start at the previous Up main signal. Both also need B-CE268, B-UPMAIN-UNTYPED and B-UPMAIN-DIAMOND.
- **Groups:** `up-main-north-to-south` (72)

### B-UPMAIN-UNTYPED (untyped_junction, evidence: unknown)

South of CE304 the Up Main passes osm-n2464365978 and osm-n13915496837: nodes with three edges and no railway=switch tag, so the importer creates no Points record and no game rule can configure them (D-029). Treating them as switches would invent topology.

- **Records:** `osm-n2464365978`, `osm-n13915496837`
- **Needed:** OSM tagging of the two junctions (survey or imagery), or a signalling diagram
- **Proposed change:** Correct the OSM tagging and re-import (infrastructure.json is generated, never hand-edited); then simple game rules and Up Main routes CE304 -> CE285 -> CE278 -> ... can be authored.
- **Groups:** `up-main-north-to-south` (72)

### B-UPMAIN-DIAMOND (crossing_not_configurable, evidence: sourced)

The Up Main south of CE304 crosses diamond osm-n3057659458 (OSM railway=railway_crossing). The game-rule model cannot configure crossings (D-029 limit), so a route over it stays unresolved.

- **Records:** `osm-n3057659458`
- **Needed:** A model decision: game-rule crossing passages (straight across, paired by continuous OSM ways, as I-012 does for slips), with conflicts at the crossing declared
- **Proposed change:** Extend GameRules with crossing rules and the C4 conflict check; a schema and validator change for a later phase.
- **Groups:** `up-main-north-to-south` (72)
